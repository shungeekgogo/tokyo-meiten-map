# 駅ちか名店マップ

東京23区の主要駅から徒歩圏にある、評価の高いレストランを地図で探せるWebアプリです。
駅と料理ジャンルを選ぶと、評価順のトップ10が一覧と地図のピンで表示されます。

- 対象駅：19駅（都心・副都心・下町・世田谷区・目黒区）
- 掲載店：約190店（食べログ「百名店」選出店が中心）
- 料理ジャンル：寿司／日本料理／天ぷら／うなぎ／とんかつ・洋食／焼鳥／焼肉／フレンチ／イタリアン・ピッツァ／ラーメン／カレー

## 使い方

### 起動

**Windows：`tokyo-meiten-map.cmd` をダブルクリック**するだけで、ローカルサーバーが起動してブラウザでアプリが開きます（Python が必要）。

- サーバーは最小化されたウィンドウ「tokyo-meiten-map server」で動きます。止めるときはそのウィンドウを閉じます。
- すでにサーバーが動いているときは、ブラウザを開くだけです。
- デスクトップなどに置きたい場合は、このファイルを右クリック →「ショートカットの作成」で作ったショートカットを移動してください（ファイル本体はこのフォルダに置いたままにします）。
- ポートは既定で 8765。変える場合は環境変数 `PORT` を指定します。

手動で起動する場合：

ローカルサーバー経由で開くのがおすすめです。

```bash
python -m http.server 8765
```

リポジトリのフォルダで実行し、ブラウザで http://localhost:8765 を開きます。

GitHub Pages など任意の静的ホスティングにそのまま置いても動きます（ビルド不要、`index.html` 1ファイル）。

### 画面の操作

| 操作 | 内容 |
|---|---|
| **駅**を選ぶ | その駅から半径約1.6km（徒歩20分程度）の店に絞り込みます。駅はエリアごとにまとめてあります。「すべて」で全駅が対象。地図上の駅名ラベルをクリックしても選べます。 |
| **料理**を選ぶ | ジャンルで絞り込みます。「総合」は全ジャンルからのトップ10。 |
| **予算**を選ぶ | 夜の予算の下限が指定額以下の店に絞り込みます（〜1万円／〜3万円）。 |
| 一覧・ピンをクリック | 店の詳細を表示します。 |

選んだ駅・料理・予算はブラウザに保存され、次回開いたときも同じ条件で表示されます。

### 店の詳細で見られるもの

- **評価**：食べログのスコアと、選出された百名店の種類
- **予算**：夜・1人あたりの目安
- **最寄り駅**：アプリ内の19駅のうち一番近い駅と、直線距離からの徒歩時間の目安
- **評価のポイント**：店の特徴の短いまとめ
- **リンク**：公式サイト（または公式サイトの検索）、Googleマップ（店内写真・口コミ）、料理の写真（画像検索）、食べログ、Retty、一休、ヒトサラ

写真は著作権に配慮し、アプリ内には掲載せずリンク先で見る形にしています。

## データについて（必ずお読みください）

| 項目 | 出典・算出方法 | 精度 |
|---|---|---|
| 店名・スコア | 食べログ「百名店」各ジャンルの選出リスト（主に2025年、とんかつ2026年、うなぎ2024年）。まとめサイト「令和Q」ほかで確認 | 発表時点の値。現在のスコアとは異なる場合あり |
| 予算 | 店の価格帯からの推定 | 目安。実際の価格は各サイトで確認を |
| 地図上の位置 | 所在地の町名からのおおよその位置 | 数百m程度ずれることあり。正確な位置はGoogleマップのリンクで確認を |
| 評価のポイント | 公開情報からの要約 | 有名店は具体的、それ以外は簡潔 |
| 公式サイト | URLを確認できた店のみ直接リンク | それ以外は「公式サイトを検索」ボタン |

- カレーの一部店舗はスコア未確認のため「百名店」と表示し、ランキングでは下位に並びます。
- 食べログ本体はボット対策により自動取得していません。Google・Retty等の評価も数値としては取り込んでおらず、リンク先で確認する形です。
- 閉店・移転・予約方法の変更がありえます。訪問前に必ず最新情報を確認してください。

## データの追加・修正

店のデータは `index.html` 内の `RAW` 配列にあります。1行1店で、形式は次のとおりです。

```js
// [名前, ジャンルID, 緯度, 経度, 食べログスコア(不明ならnull), 予算下限, 予算上限, 地区, 評価のポイント, 公式URL(任意)]
['鮨 さいとう','sushi',35.6664,139.7398,4.60,40000,60000,'六本木一丁目','東京で最も予約が取りにくい鮨店の一つ。'],
```

- ジャンルIDは `GENRES` 配列（`sushi`, `washoku`, `tempura`, `unagi`, `katsu`, `yakitori`, `yakiniku`, `french`, `italian`, `ramen`, `curry`）から選びます。
- 最寄り駅は緯度経度から自動で計算されます。
- 駅を追加するときは `STATIONS` 配列に追加し、`AREAS` 配列のどれかのエリアに駅IDを加えます。
- 駅からの対象範囲は `RADIUS`（メートル）で変更できます。

## 技術メモ

- 単一HTMLファイル。外部依存は Leaflet 1.9.4（cdnjs）、国土地理院の淡色地図タイル（APIキー不要）、Google Fonts のみ。OpenStreetMap公式タイルは利用ポリシーによりアクセスが拒否（403）されるため使っていません。
- ライト／ダークモードはOSの設定に追従します（ダーク時は地図タイルを反転表示）。
- スマートフォン幅（〜820px）では地図が上、一覧が下の縦並びになります。
